# Sequences

They are lists of elements that may have repititon.
For example, the sequence (1, 1, 2, 2, 3, 3).
or (1, 3, 5).


There are two types of sequences that have a common difference between each number as far as I know of, Geometric and Arithmetic


## Arithmetic

An arithmetic sequence changes by adding or subtracting a fixed amount (the common difference) between each step.

For example, the sequence (1, 2, 3, 4, 5).

## Geometric

 A geometric sequence changes by multiplying or dividing by a fixed amount (the common ratio) between each step.

 For example, the sequence (1, 3, 9, 27).
